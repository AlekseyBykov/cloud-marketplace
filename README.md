## Cloud Marketplace

Cloud Marketplace is a reference implementation of a microservices-based system built with the Java ecosystem.

It is designed as an architectural playground to explore service decomposition, reactive processing, and event-driven communication.

### Services

- [cloud-marketplace-menu-service](https://github.com/AlekseyBykov/cloud-marketplace-menu-service) - RESTful CRUD service for managing menu items.
- [cloud-marketplace-orders-service](https://github.com/AlekseyBykov/cloud-marketplace-orders-service) - Reactive order processing (Spring WebFlux).
